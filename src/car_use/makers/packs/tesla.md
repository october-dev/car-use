# Tesla

## Talking to the car
- Teslas are electric, so there are no engine emissions to report, and a generic OBD-II adapter shows little or nothing. That is normal, not a fault. [common]
- Tesla's supported way in for third-party apps is the Fleet API (https://developer.tesla.com). It needs a registered app and a "virtual key" that the owner adds in the Tesla app. car-use's Tesla backend is on the roadmap, not built. [verified: developer.tesla.com]
- Tesla's own service tool is Toolbox. [common]
